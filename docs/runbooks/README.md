# Runbooks

This lane holds operator procedures. A runbook should tell someone how to
perform, verify, pause, roll back, or investigate a repository operation.

Use this lane when a document is mainly:

- A dispatch or manual execution procedure.
- A rollback or emergency response recipe.
- A local setup, maintenance, or troubleshooting workflow.
- A recurring review procedure.
- A checklist whose value depends on a human applying it to a specific
  event.

Do not put the repository's normative contract here when it can stand on
its own. Put adopted rules in `docs/standards/`, then link to the
runbook for concrete commands and operational sequencing.
